Privacy Policy

Hairat Box Uploader · Last updated: 24 November 2026

What this app is

Hairat Box Uploader is a private tool used only by the owner of the Hairat Box YouTube channel to upload the channel's own videos. It is not a public service.

Data we access

With the owner's permission, the app uses the Google OAuth scope https://www.googleapis.com/auth/youtube.upload to upload videos, titles, descriptions and tags to the owner's own YouTube channel. It does not read, collect or store any other Google user data, and it does not access other people's accounts.

Storage and sharing

The access credential is stored only as an encrypted secret in the owner's private GitHub repository. No data is sold, shared with third parties, or used for advertising.

Google API Services

The app's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. It also uses YouTube API Services; see the YouTube Terms of Service and the Google Privacy Policy.

Removing access

Access can be revoked at any time at myaccount.google.com/permissions.

Contact

For questions, contact the Hairat Box channel through its YouTube "About" page.
